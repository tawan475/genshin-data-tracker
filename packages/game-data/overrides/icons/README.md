# overrides/icons

Drop `<icon name>.png` (or `.webp`, `.jpg`) here for an icon no source has, or
to replace a bad one, e.g. `UI_ItemIcon_100004.png`. Files here win over Enka,
gi.yatta.moe and static.nanoka.cc. Then run `pnpm --filter @gdt/game-data icons`.
Square images of 128 px or more work best.
